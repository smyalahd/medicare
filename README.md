# MediCare – Healthcare Website

A modern, responsive healthcare website concept built with **Next.js, React, TypeScript, and Tailwind CSS**.

MediCare provides a user-friendly interface for exploring doctors, browsing medical specialties, viewing doctor profiles, and interacting with a demo appointment booking experience.

## Features

- Responsive design for desktop and mobile devices
- Doctor directory with search functionality
- Filter doctors by medical specialty
- Individual doctor profile pages
- Doctor-specific appointment schedules
- Date and time slot selection
- Appointment availability validation
- Prevention of booking past appointment times
- Interactive contact form
- Mobile-friendly navigation
- Dedicated login and signup pages
- Modern healthcare-inspired user interface

## Pages

| Page | Description |
|---|---|
| **Home** | Healthcare landing page with services and contact section |
| **Doctors** | Browse, search, and filter doctors |
| **Doctor Profiles** | View individual doctor information and specialties |
| **Appointment Booking** | Select dates and available time slots |
| **Contact** | Interactive demo contact form |
| **Login / Signup** | User authentication interface concepts |
| **Articles** | Article pages and healthcare-related content structure |

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/smyalahd/medicare.git
```

Navigate to the project directory:

```bash
cd medicare
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## Demo Information

MediCare is a portfolio demonstration project.

- Doctor profiles contain fictional demonstration data.
- Appointment bookings are not real reservations.
- Contact form messages are not transmitted or stored.
- Login and signup pages are frontend demonstrations.
- No backend or database is currently connected.
